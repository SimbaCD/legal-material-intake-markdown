# Material Intake Markdown Output Format

## 1. 材料清单

```markdown
# [案件名] 材料清单

| 序号 | 原文件 | 材料产生时间 | 材料名称 | 分类目录 | 规范文件名 | 输出 Markdown | 类型 | 是否 OCR | 引用建议 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|
```

## 2. 阅读顺序

```markdown
# [案件名] 阅读顺序

## 优先阅读
- 

## 第二轮阅读
- 

## 待人工复核
- 
```

## 3. 单份材料 Markdown

```markdown
# [材料标题]

- 原文件：
- 材料产生时间：
- 材料名称：
- 分类：
- 规范文件名：
- 类型：PDF / 扫描型 PDF / DOCX / 内容截图 / 聊天记录 / 图片证据
- 来源：
- 是否 OCR：是 / 否
- 处理说明：
- 引用建议：可直接引用 / 需人工复核

## 正文
```

## 4. 图片证据索引

不适合强行 OCR 成正文的图片，输出为图片证据索引：

```markdown
# [材料标题]

- 原文件：
- 材料产生时间：
- 材料名称：
- 分类：
- 规范文件名：
- 类型：图片证据
- 来源：原始图片目录
- 是否 OCR：否
- 处理说明：现场/实物/伤情类图片按图片证据索引处理，未强行 OCR 为正文
- 引用建议：需结合原图人工复核

## 图片证据索引

- 原图路径：
- 复核事项：
```

## 5. 输出纪律

- 每份材料都要能从 `00_材料清单.md` 回到原文件和处理后 Markdown。
- OCR 质量、材料来源、材料时间或版本不确定时，写入 `Z_待人工复核` 或清单备注。
- 单份材料正文只承载原始材料转换结果和必要整理说明，不在材料整理阶段加入法律结论。
